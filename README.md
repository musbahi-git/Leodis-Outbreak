# Leodis: Outbreak

A private outdoor manhunt game for Leeds city centre and the University of Leeds.
Players are **runners** or **hunters**. Hunters receive periodic location reveals.
Captured runners become hunters.

- Long-term capacity target: 250 simultaneous players.
- First playable target: 10–20 players in one bounded area.
- Priority: a finished, demonstrable small version before a large platform.

## Tech

- Unity **6000.6.8f1** (Unity 6.6), Universal Render Pipeline, Input System, UI Toolkit.
- Player app: Unity + C#. Portrait only. Bundle id `com.musbahi.leodisoutbreak`.
- Builds: Unity Build Automation (cloud). No local Xcode or Mac required.
- Backend: not decided yet. The app talks to an `IGameBackend` interface; the current
  implementation is an on-device simulation (`LocalDemoBackend`).

## Run it

1. Open the project in Unity 6000.6.8f1 and wait for scripts to compile.
2. Menu **Leodis > Setup > Rebuild Bootstrap Scene** (one-off after pulling, or whenever the
   scene should be regenerated). This creates the camera, event system, UI document and
   panel settings and sets Bootstrap as the only build scene.
3. Press Play. Tap **Start**: the status changes to `Started`, then the demo session begins.
4. **Leodis > Setup > Validate Project Settings** reports identifier, orientation and scene problems.
